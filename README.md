# Vexel

Библиотека для создания интерактивных, шустрок-действующих TUI (Terminal User Interface) на ванильном Rust2.

## Структура проекта:
vexel/
├── src/
│ ├── lib.rs // Основные структуры
│ ├── render.rs // Рендерер 
│ ├── events.rs // Обработка событий
│ └── core/
│ ├── app.rs // AppState и методы
│ └── element.rs // Конструкторы элементов
├── Cargo.toml
└── README.md

## Основные Структуры:

AppState
├── elements: Vec<Element>      // плоский массив всех элементов
├── root: usize                 // индекс корневого элемента
└── dirty: Vec<usize>           // индексы элементов, которые нужно перерисовать

Element
├── id: String
├── kind: ElementKind           // Box | Text | Button | Input
├── data: ElementData           // данные элемента
├── style: Style                // стили элемента
├── children: Vec<usize>        // индексы детей
├── parent: Option<usize>       // индекс родителя (у корня — None)
├── dirty: bool                 // нужно ли перерисовать
└── focusable: bool             // может ли получать фокус

Style
├── x: i16, y: i16              // позиция относительно родителя
├── width: u16, height: u16     // размер
├── color: Color                // цвет элемента
├── background: Option<Color>   // фон
├── border: Option<Border>      // бордер
├── padding: usize              // внутренний отступ
├── margin: usize               // внешний отступ
└── visible: bool               // видимоть
